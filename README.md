# MH ModPacks

Public metadata repository for MH ModPacks Installer.

`manifest.json` = catalog; `installer/` = remote installer settings; `changelogs/` = update notes; `packs/` = per-version manifests.

Do not commit third-party mods unless redistribution is permitted. Prefer GitHub Releases/CDN for large binary files and reference their URLs + SHA-256 from pack manifests.
